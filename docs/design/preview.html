Open Aria Echo · 浏览器端 v2 —— 相机仪表重构

在 Echo Web 浏览器端还原稿（取自 openaria-echo-web 现状）的基础上完全重排布局。设计语言不动：纯黑取景底、信号色配额、等宽数字、能力未声明不画控件、录制指示常亮无循环动画、Conductor 拥有权威状态。变的是层级与结构——把散落的玻璃盒子收进两条仪表轨与一块实心相机操作台。

取景器：真正铺满 + 相机取景框

  • 顶栏是 50 高的渐隐信息条，只压最上沿：机身名 + 链路点、状态印、余量/温度、Wi-Fi 网络入口、链路状态，右端两枚 38 图标键（会话 / 设备）——都收在这一条里，不再占用侧边。
  • 四边取景刻度与中心十字线框住 letterbox；双目并置画面加大到接近真实 32:9 的高度，减少上下黑边。
  • 状态不再是弱小的方点 chip，改为左侧 3px 色条的状态印：▌待机 / ▌■ 录制中。

取景工具收成一条横条

  • 左上角一排横向工具条：[双目│左眼│右眼] 段选 + 全画幅 + PEAK（内嵌阈值条与数值）——不再是占一整列的竖轨。
  • RAW IMU 收进左下角一行等宽计数器：a … ω … ≈ good。
  • 系统入口全在顶栏：会话 / 设备是图标键，网络沿用还原稿的 Wi-Fi 文字入口（带下划线）。

相机操作台（底部实心区）

  • 不再是半透明糊在一起的一条：实心 #0a0c0d 台面 + 硬顶边，三区分明。
  • 左：录制 | 标定 段选（把「标定录制」按钮并入模式），下面是放大到 74 的快门——空闲红圆 / 录制红方 / 锁定变暗。
  • 中：命名（空闲）或 当前会话名 + UUID（录制）。
  • 右：时长 / 帧数 / 写入 / 校验 读数，等宽 22，实时走 live、空闲走 ink-3，去掉包边只留细分隔。

面板：给语义以形状

  • 会话详情把生产方声明 vs 消费方判断做成并排两枚印章——这是产品的核心语义，必须一眼看到。
  • 设备页存储改为容量条；会话台账每行左侧 3px 状态色条 + verdict。
  • 每个 section 头部一根 3px tick + 等宽小标题，层级立起来。

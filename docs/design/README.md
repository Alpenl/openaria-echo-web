## v2 相对基线的改动

设计语言不变：纯黑取景底、信号色配额（`--record` / `--caution` / `--positive` / `--live` / `--peak`）、
等宽数字读数、能力未声明不画控件、录制指示常亮无循环动画、Conductor 拥有权威状态。

结构变化：

- **顶栏**：60 高玻璃厚条 → 50 高渐隐信息条（`linear-gradient` 压最上沿，不再是实心 slab）。
  机身名 + 链路点、状态印、余量/温度、`Wi-Fi` 网络入口、链路状态，右端两枚 38 图标键（会话 / 设备）。
- **状态**：弱方点 chip → 左侧 3px 色条的**状态印**（`▌待机` / `▌■ 录制中 · 04:12`）。
- **取景工具**：左上竖排堆叠 → 一排**横向工具条**：`[双目│左眼│右眼]` 段选 + 全画幅 + PEAK（内嵌阈值条与数值）。
- **RAW IMU**：竖排卡片 → 左下角一行等宽计数器。
- **取景框**：四边刻度 + 中心十字线；双目并置画面加大到接近真实 32:9 的 `contain` 高度，收窄上下黑边。
- **底部操作台**：半透明糊 → **实心 `#0a0c0d` 台面 + 硬顶边**，三区分明。
  左：`录制 | 标定` 段选（把「标定录制」按钮并入模式）+ 放大的快门；中：命名 / 当前会话名 + UUID；
  右：`时长 / 帧数 / 写入 / 校验` 读数放大到等宽 22，去包边留细分隔。
- **面板**：每个 section 头部一根 3px tick + 等宽小标题；会话详情把
  **生产方声明 vs 消费方判断**做成并排两枚印章；设备页存储改**容量条**；会话台账每行左侧 3px 状态色条。

Open Aria Echo · 浏览器端（Web）界面还原稿

反向整理自 openaria-echo-web 的 Preact 实现（src/ui/* + src/styles/app.css，HEAD d3e7b74）。这是 Conductor 打包并在设备本地托管的浏览器客户端，与 v1/v2/v3 里的安卓 App 是两个不同的前端，因此单开一页、不与移动端混排。所有尺寸、颜色、字号、状态文案均取自代码，不是重新提案。

取景器优先的三层外壳

  • 画面铺满整个视口（.frame position:absolute; inset:0），顶栏、底栏、面板都是浮层压在画面之上。
  • 顶栏 60 玻璃条：品牌方块 + 机身名，状态片，右侧等宽事实（余量/可写、温度、连接方式按钮、链路点），再两个 44 图标键（会话台账、设备与链路）。网络面板由「连接方式」按钮打开。
  • 底栏 min 120 玻璃条：76 圆形快门 + 命令区（录制名称输入 / 当前会话名+UUID）+ 4 格读数（时长/帧数/写入/校验）+ 标定录制按钮。
  • 左上浮层 .stage-left：取景切换（双目/左眼/右眼）竖排、峰值对焦（PEAK + 阈值滑杆）、RAW IMU 卡、单眼时的「已裁切取景 · 看全画幅」。
  • 右侧面板 min(420px, 92vw) 从右缘拉出：会话台账 / 会话详情 / 设备与链路 / 网络设置；窄屏（<860）改为底部抽屉、默认单眼取景。

信号色配额（越界即错）

  • #ff3b2d record — 仅 device_state=recording，实心红。
  • #ff3b2d + 斜纹 fault — blocked / failed / unusable。
  • #e0a020 caution — 收尾 / 校验 / 降级 / 尚未校验 / 断线。
  • #46c98a positive — 已连接、消费方判定可用。
  • #7fe3f5 live — 仅实时数值前景，绝不作背景。
  • #e858ff peak — 仅峰值对焦辅助，不参与状态语义。
  • 全站无循环动画：录制指示常亮。

不能动的语义（README）

  • 设备状态与会话生命周期的唯一权威是 Conductor 的 capture daemon；页面只投影权威快照，不产生本地乐观状态。
  • 能力未声明就不画控件（对焦、标定、网络切换均按设备声明门禁），不给一个按下去无效的键。
  • 生产方声明（sealed）与消费方判断（gateway verdict）分开显示；只有判为 usable 的不可变快照才出现下载入口。
  • 危险带只投影权威快照里的持久失败，刷新页面不会把旧终态重放成新告警。
